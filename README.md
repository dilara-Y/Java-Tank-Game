# 🎮 Tank Battle Game

A 2D tank battle game built with Java and JavaFX.  
Players control tanks, avoid obstacles and destroy enemies.

## Features
- Player-controlled tank movement
- Collision detection system
- Enemy AI
- Interactive UI with JavaFX

## Technologies Used
- Java
- JavaFX
- OOP Design Patterns

## How to Run
1. Clone the repository
```
   git clone https://github.com/dilara-Y/tank-battle-game.git
```
2. Open with IntelliJ IDEA — File → Open → select the project folder
3. Run `Main.java`
